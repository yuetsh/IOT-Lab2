# 各功能区域设备清单

| 功能区域 | 设备 | 功能说明 |
|----------|------|----------|
| 大门区域 | 人体红外传感器、ADAM-4150 数字量采集器 | 检测人员靠近时自动开启大门 |
| 身份识别 | 超高频中距离一体机、超高频标签、红外对射传感器、ADAM-4150 数字量采集器、继电器、LED 灯、报警灯 | 门闸刷卡完成身份识别与人数统计，非法闯入时触发报警 |
| 大厅安防 | 温湿度传感器、空气质量传感器、二氧化碳传感器、烟雾传感器、火焰传感器、ADAM-4150 数字量采集器、ADAM-4017 模拟量采集器 | 监测大厅环境，自动控制空调及相关设备，进行火灾安防预警 |
| LED 显示 | LED 显示器、串口服务器 | 推送时间、环境、安防等各类信息，供大厅人员查看 |
| 绿色植物 | 土壤水分传感器、水箱、雾化器、水温传感器、加热棒、液位传感器、智能插座、ZigBee 协调器、ZigBee 四输入量采集器、ADAM-4150 数字量采集器 | 自动监测土壤水分并为绿植浇水、加湿 |
| 自助系统 | 超高频中距离一体机、超高频标签、电子扫描枪、小票打印机 | 为读者提供图书借还、查询、续借等自助服务 |
